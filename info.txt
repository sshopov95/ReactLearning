*-3 Desctruct-*
Така не: 
function printUser({name,age}){
    console.log(`${name} is ${age}`)
}

Така:
function printUser({name,age}: {name:string; age:number}){
    console.log(`${name} is ${age}`)
}

*-4 Killing the idea of typescript!-*
function identity (value:any){
    return value;
}

const result1 = identity('1');
result1.toFixed(); - гърми!

const result2 = identity(1);
const result3 = identity(true);

Как трябва да изглежда за такива generic функции:
function identity<T> (value:T){
    return value;
}

const result1 = identity<string>('hello');
result1.toUpperCase(); - работи

const result2 = identity<number>(44);
result1.toFixed(2); - работи
